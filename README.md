## 🚀 Quickstart & Local Development

### 1. Clone the Repository
```bash
git clone https://github.com/Abdullah-Al-Raju/milli-plays.git
cd milli-plays
```

### 2. Run Locally with Any HTTP Server
```bash
# Using Python built-in server
python3 -m http.server 8080 --directory cf-pages-arena
```
Open **`http://localhost:8080`** in your browser to launch the luxury dark neo-skeuomorphic dashboard!

### 3. Run with Cloudflare Wrangler CLI
```bash
npx wrangler pages dev cf-pages-arena
```

## 🎨 Design Philosophy: Obsidian & Amber Neo-Glass

The Milli UI is crafted around an ultra-premium dark skeuomorphic aesthetic:
- **Obsidian Canvas:** Deep charcoal and volcanic glass (`#090b0e`, `#12151c`).
- **Warm Radiant Amber Lighting:** Subtle ambient sunset gradients (`rgba(255, 122, 48, 0.18)`).
- **Physical 3D Skeuomorphism:** Overlapping stacked core cards with metallic gold SIM microchips, tactile rounded bevels (`border-radius: 20px`), and frosted glass popovers.
- **Micro-Interactions:** Quick-launch command palette accessible anytime via `⌘ + Space` or `⌘ + K`.
